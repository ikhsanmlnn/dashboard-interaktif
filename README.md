Dashboard interaktif untuk menganalisis dataset **Auto MPG** menggunakan *Python Panel* dan *hvPlot*.

## Deskripsi
Proyek ini menampilkan visualisasi interaktif yang memudahkan pengguna dalam memahami hubungan antara:
- Efisiensi bahan bakar (MPG)
- Jumlah silinder
- Tahun produksi mobil
- Asal mobil (Amerika, Eropa, Asia)

## Teknologi yang Digunakan
- Python
- Panel
- hvPlot
- Pandas
- Jupyter Notebook
- Git & GitHub


## Fitur Dashboard
1. **Tren Rata-rata MPG per Tahun**  
   Menampilkan perkembangan efisiensi bahan bakar dari tahun ke tahun.

2. **Rata-rata MPG Berdasarkan Silinder**  
   Membandingkan efisiensi bahan bakar berdasarkan jumlah silinder.

3. **Distribusi Nilai MPG Berdasarkan Asal Mobil**  
   Menunjukkan persebaran nilai MPG dari tiap wilayah asal kendaraan.
